# 📊 Sales Performance Dashboard | Tableau

## 📌 Project Overview

The **Sales Performance Dashboard** is an interactive Tableau dashboard designed to analyze sales performance across different regions, product categories, customers, discounts, and returns.

The dashboard transforms raw sales data into meaningful visual insights to help understand business performance and identify important sales trends.

## 🎯 Objectives

- Analyze overall sales performance
- Identify sales trends over time
- Compare quantity sold across different regions
- Understand sales distribution by product category
- Analyze the relationship between unit price and quantity sold
- Monitor average discount
- Track product return rate
- Provide an interactive and easy-to-understand business dashboard

## 🛠️ Tools & Technologies

- **Tableau** – Dashboard development and data visualization
- **Microsoft Excel** – Data preparation and dataset management
- **Data Analysis** – Sales and performance analysis
- **Data Visualization** – Interactive charts and KPIs

## 📊 Dashboard Features

### Key Performance Indicators (KPIs)

- 💰 Total Sales
- 📉 Average Discount
- 🔄 Return Rate

### Visualizations

- **Quantity Sold by Region**
- **Sales Trend Over Time**
- **Sales Distribution by Category**
- **Unit Price vs Quantity**
- **Average Discount**
- **Total Sales**
- **Return Rate**

## 📈 Key Analysis

The dashboard provides insights into:

- Regional sales and quantity performance
- Changes in sales over time
- Product category contribution
- Pricing and quantity relationships
- Discount patterns
- Customer return behavior
- Overall sales performance

## 🧮 Calculated Fields

The Tableau dashboard includes calculated fields such as:

- **Profit**
- **Return Rate**

These calculations help provide additional business insights beyond the raw dataset.

## 📂 Dataset

The dataset contains sales-related information including:

- Date
- Customer
- Region
- Category
- Product
- Quantity
- Unit Price
- Discount
- Returned
- Total Sales
- Average Discount
